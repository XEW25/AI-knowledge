## 已核实事实(自读全文,2026-08-06)

- **作者**: Christopher Agia, Rohan Sinha, Jingyun Yang, Zi-ang Cao, Rika Antonova, **Marco Pavone**, **Jeannette Bohg**(Stanford 系;机构行未逐字核对)
- **两个互补检测器**:**STAC**(Statistical Temporal Action Consistency)管 **erratic failures**;**VLM 运行时监控**管 **task progression failures**

### STAC 机制
- 生成式策略每次输出 **action chunk**(预测 horizon `h`),每 `k` 步重规划;⇒ **t 时刻与 t+k 时刻的 chunk 在时间上重叠**
- STAC = 两个分布在重叠窗口上的**统计距离** `D(π̄_t, π̃_{t+k})`
- **假设(原文)**:预测型策略相当于"**possessing an internal world model**";分布内 → 内部模型准 → t 时刻隐含预测的 `s_{t+k}` 与实际吻合 → 早先的动作分布依然合理 → **距离小**;OOD → 内部模型错 → **距离大**
- **实现**:**MMD + RBF 核**的经验距离(解析计算不可行:要 marginalize 掉非重叠动作 + diffusion 中间去噪步);高多模态域采 **B=256** 条动作序列
- **校准**:只需**少量成功 rollout** `D_τ`;附录含 **"Conformal guarantee of STAC" + 证明**
- **策略无关**:"STAC is **agnostic to the generative policy formulation**"(对比 DDPM-loss baseline 只适用于 diffusion)

### VLM 监控
- **不微调**:零样本 prompt 现成闭源模型 —— **GPT-4o / Claude 3.5 Sonnet / Gemini 1.5 Pro**,"use **consistent prompts** across all models"
- **输入**:抽帧**视频** `I_{0:t} = (I_0, I_{νk}, I_{2νk}, …, I_t)`(约 **1Hz**,ν∈{1,2} 即足够辨认运动)+ 任务描述 + **时间限制** + **已用时间**
- **prompt 三段式**:Questions(先自生成任务相关问题)→ Answers(细粒度视觉细节)→ Analysis(判断;**显式要求对比已用/限时**,且"除非不太可能在限定时间内完成否则不要判失败"——防误报)
- 变体:Video QA / **+ Success Video** / **+ Goal Images** / Image QA(消融"视频 vs 单图")
- **调用频率**:实验中**每 episode 仅查 2 次**;理由 ① 不推进失败发生在更长时标,查密了无意义变化 ② 闭源 VLM **贵**(STAC 成本可忽略) ③ **不推进失败不需要立即干预**(与 erratic 相反)
- **非阻塞 API 调用** ⇒ 不卡控制环

## 结果(核实数字)

| 项 | 数值 |
|---|---|
| STAC 检出 erratic 失败 | **99%** |
| Sentinel(STAC+VLM 并行)检出未知失败 | **>97%**(跨仿真+真机) |
| 组合 vs 单用任一 | **+18%** |
| task progression:STAC 单独 TPR | **44%**(时间上自洽的失败漏掉) |
| task progression:组合 | **93% TPR**,FPR 仅 +7% |
| erratic:VLM 单独 TPR | **77%**(视觉上细微)且**显著更慢** |
| **真机 Push Chair 总准确率** | **95%**;VLM 在真机 **90% TPR / 100% TNR**(优于仿真,视觉域差距更小) |
| Close Box:STAC 漏掉的 task-progression 失败 | 35% |
| Cover Object 最佳 VLM | Claude 3.5 Sonnet **79% TPR / 84% TNR**(Video QA);Close Box 最佳为 GPT-4o |

## 关键消融(解释"为什么必须是分布距离")
- **PushT(多模态域)中 STAC 是唯一 balanced accuracy >90% 的方法**
- **用非统计距离(如 min. distance)测时序一致性,表现比 baseline 还差——因为它忽略了动作多模态性**
- 给 baseline 加时序一致性**至多带来边际提升** ⇒ 起作用的是"时序 × 统计"的组合,不是任一单独
- **horizon 敏感**:k=2 → TPR 61%;k=4 → 78%;**k=8(h=16,标准设定)→ 95%**
- ⚠️ baseline 里有 **Diffusion Output Variance**(对 B 条采样算方差)——**即"看采样方差"这一朴素做法,被 STAC 胜过**;原文另指出它"does not quantify epistemic model uncertainty"

## 实验设置
- 域:**PushT**(测多模态)、**Close Box** / **Cover Object**(双移动机械臂,**14-DoF**)、**Push Chair**(真机,7-DoF 单臂移动操作,非抓取式)
- 策略:diffusion policy;演示数 200 / 50 / 50 / **15(真机)**;仿真用 PointNet++ 编码器版 DP,真机用 **EquiBot**(SIM(3)-等变 DP);**N=100** 去噪步
- OOD 制造方式:随机化物体**尺度/尺寸**(PushT, Close Box)与**位姿**(Cover Object, Push Chair),超出演示数据范围
- 指标:TPR / TNR / FPR / **Detection Time** / accuracy / balanced accuracy
- 观察:"generative policies tend to fail **erratically** in the Close Box domain, but **smoothly** in the Cover Object domain" —— **失败模态与域相关**
